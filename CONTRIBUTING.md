# Contributing to StorePOS

Thanks for helping! Small contributions are welcome.

1. Fork the repo and create a branch: `git checkout -b feat/my-change`
2. Set up: `cd server && npm install && cp .env.example .env`
3. Make your change and add or update a test in `server/test/`
4. Run `npm test` and make sure everything passes
5. Open a pull request describing **what** changed and **why**

Look for issues labeled `good first issue`. Never commit `.env` or real customer data.
